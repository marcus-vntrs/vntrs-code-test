# Backend: NodeJS + TypeScript + Express

This template provides a minimal setup to get Backend in NodeJS working with Express with some ESLint rules.

The Backend is based on this API: https://jsonplaceholder.typicode.com/

1. *Install Packages*:
    ```sh
    cd ./backend && npm install
    ```

3. *Start Project*:
    ```sh
    npm run dev
    ```

# Frontend: React + TypeScript + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

1. *Install Packages*:
    ```sh
    cd ./frontend && npm install
    ```

3. *Start Project*:
    ```sh
    npm run dev
    ```
